About Lazarus Ebi

I am a Cybersecurity & Software Engineer and systems researcher. My engineering approach combines low-level software architecture, deep operating system internals, and proactive threat modeling.

I investigate vulnerabilities from the ground up: examining heap layout corruptions, CPU cache timing side-channels, and instruction pointer hijacking via Return-Oriented Programming (ROP). To defend systems, I build resilient tooling in Rust, C, and Python, while utilizing eBPF, SecComp, and kernel probes to detect adversary tactics in real time.

Whether building secure microservices with zero-trust mTLS, auditing applications against the OWASP Top 10, or reversing compiled binaries, I prioritize memory safety, automated verification, and high-fidelity detection engineering.
